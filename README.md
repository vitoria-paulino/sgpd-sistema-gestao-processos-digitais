# SGPD — Sistema de Gestão de Processos Digitais

## Sobre o projeto

O Sistema de Gestão de Processos Digitais (SGPD) é um projeto acadêmico desenvolvido durante a graduação em Gestão da Tecnologia da Informação, com foco na melhoria e organização de processos do setor de Recursos Humanos.

## O problema

O processo de gestão de vagas e documentações do RH dependia de planilhas e atividades manuais. Isso dificultava o acompanhamento das etapas, a organização das informações e a comunicação entre os envolvidos.

Também foram identificados problemas como falta de padronização, informações descentralizadas, retrabalho e dificuldade para visualizar o andamento dos processos.

## Objetivo

Propor uma solução digital capaz de centralizar informações, organizar o fluxo dos processos e facilitar o acompanhamento das atividades do RH.

A proposta busca reduzir tarefas manuais, melhorar a comunicação entre os envolvidos e proporcionar maior organização e visibilidade dos processos.

## Solução proposta

Foi estruturada uma solução integrada para o gerenciamento dos processos, considerando as necessidades dos profissionais envolvidos.

O projeto foi desenvolvido a partir do levantamento e organização dos requisitos, modelagem dos processos e criação de protótipos da solução.
